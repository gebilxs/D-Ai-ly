LobeHub 一线复盘：实践 Super-Agent 半年后，我们对于 Agent 工程的思考

智源社区 2026-11-19 来源归档

本文为LobeHub团队在多人协作场景下落地Super-agent的工程复盘。不同于单人聊天框中的双层Agent调度，团队将多模型Agent嵌入Discord频道与任务看板，与人类混编协同研发。实践发现，仅依赖Session机制无法满足跨成员、跨任务、长周期的上下文一致性与状态隔离需求，必须构建独立的Agent运行时环境，以支撑身份识别、权限控制、状态持久化及协作审计等关键能力。
