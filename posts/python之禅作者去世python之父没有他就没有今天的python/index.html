《Python之禅》作者去世，Python之父：没有他就没有今天的Python

智源社区 2026-11-13 来源归档

Python之父Guido van Rossum宣布，《Python之禅》作者Tim Peters去世。该诗共19行，包含“优美胜于丑陋”“显式胜于隐式”“简单胜于复杂”等核心编程哲学，深刻影响Python社区与开发者价值观。Peters早年即为Python核心贡献者，在《Python之禅》问世前已是Guido的重要合作者。他以简洁、优雅、务实的代码理念塑造了Python文化，其思想超越语言本身，成为软件工程的重要精神遗产。业界深切缅怀这位低调而深远的编程思想家。
