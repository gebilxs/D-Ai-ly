西湖大学团队提出Code World Model：让Coding Agent成为世界模型的大脑

智源社区 2026-09-02 来源归档

世界模型要支持开放世界交互，关键在于建模长期、隐性、动态的因果演化，而非仅生成连贯视频。复杂环境中，实体、关系、规则与事件持续变化，动作影响常具延迟性与扩散性。如游戏中刺杀统治者，其后果会逐步波及继承秩序、派系联盟、贸易网络及NPC的信念与行为，且这些变化在脱离玩家视野后仍持续演进，要求模型具备跨时空的状态追踪与因果推理能力。
