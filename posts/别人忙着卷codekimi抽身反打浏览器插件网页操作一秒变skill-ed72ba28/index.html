别人忙着卷Code，Kimi抽身反打浏览器插件：网页操作一秒变Skill

智源社区 2026-09-26 来源归档

Kimi近期推出新版浏览器扩展，实为4个月前发布的Kimi WebBridge升级版，功能增强，支持网页打开、内容读取与交互操作。此前刚发布Kimi Code Desktop，将浏览器嵌入本地窗口，引发用户对其技术路线“复古”的调侃。新插件延续其AI辅助浏览定位，但未脱离浏览器依赖，被质疑创新不足。尽管名称更新、体验优化，核心逻辑仍属网页增强型工具，尚未实现真正去浏览器化或深度系统集成。
