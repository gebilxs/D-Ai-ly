突发！Claude Code全面开放，接入AGENTS.md

智源社区 2026-09-20 来源归档

Claude Code团队在2.1.277版本中正式支持AGENTS.md文件，当项目中缺失CLAUDE.md时自动 fallback 读取AGENTS.md。该更新由核心工程师Thariq在X平台宣布，一小时内浏览破百万，GitHub更新日志首行即标注此功能。开发者已期待逾一年，此前社区长期呼吁支持AGENTS.md标准以提升多智能体协作兼容性，此次更新标志着Claude Code在工程实践与开源生态适配上的重要让步。
