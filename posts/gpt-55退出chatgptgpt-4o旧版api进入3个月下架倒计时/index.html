GPT-5.5退出ChatGPT！GPT-4o旧版API进入3个月下架倒计时

智源社区 2026-10-16 来源归档

GPT-5.5于10月14日正式退役，停止在ChatGPT、ChatGPT Work及通过ChatGPT账号登录的Codex中服务；但API接口及使用API Key登录Codex的会话不受影响。该模型此前未被OpenAI官方正式命名或广泛宣传，疑似内部代号或误传版本，其退出标志着OpenAI模型迭代节奏加快。目前GPT-4仍为公开可用主力版本，而市场对下一代模型GPT-5的期待持续升温。此次调整属服务端优化，用户无需迁移数据或更改配置。
