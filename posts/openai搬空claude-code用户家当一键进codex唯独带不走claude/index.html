OpenAI搬空Claude Code！用户家当一键进Codex，唯独带不走Claude

智源社区 2026-08-14 来源归档

AI编程工具迁移的最大成本并非订阅费用，而是用户长期积累的个性化资产：如定制化的CLAUDE.md文档、数十个实操技巧、MCP服务器授权配置及熟记于心的斜杠命令等。这些无需付费却高度私有化的“家当”，构成了AI助手高效工作的核心说明书。一旦切换至Codex等新平台，原有配置即失效，需全部重写重配。正因如此，开发者真正难以割舍的，正是沉淀在本地、历时半年打磨而成的专属工作体系与习惯生态。（150字）
