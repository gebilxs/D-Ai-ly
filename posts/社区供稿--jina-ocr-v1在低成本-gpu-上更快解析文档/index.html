社区供稿 | jina-ocr-v1：在低成本 GPU 上更快解析文档

智源社区 2026-09-24 来源归档

Jina-OCR v1 是由 Jina AI 推出的开源 OCR 模型，支持多语言文本检测与识别，在复杂背景、低质量图像及手写体上表现优异。该模型已在 Hugging Face 和 ModelScope 平台开源，提供便捷的推理接口与预训练权重。技术报告（arXiv:2609.03181）详述其基于视觉 Transformer 的端到端架构、高质量合成数据策略及跨语言泛化能力。官方提供稳定 API 服务（jina.ai/models/jina-ocr-v1），便于集成至各类文档理解与自动化流程中，显著提升
